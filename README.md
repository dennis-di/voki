# Voki

Vokabel-App für Französisch und Englisch: Vorlesen, Buchstabieren, Dauerschleife, Schaukel-Modus, Units per Foto.

- **Units → Seiten → Abschnitte**, männlich/weiblich farbig (blau/rot wie im Buch), Beispielsätze, Hinweise und orange Merk-Regeln
- **Lernweg mit 4 Stufen**: Neu → Erkennt (Auswahl FR→DE) → Ordnet zu (Auswahl DE→FR) → Sitzt (richtig geschrieben)
- Schreibprüfung unterscheidet Artikel-, Akzent- und Buchstabenfehler, mit Buchstaben-Vergleich
- Weitere Modi: Auswahl, Schreiben, Diktat, Satz-Puzzle, Generalprobe (mit Zeit)
- **Test-Countdown**: Testdatum eintragen, tägliche Portion, Generalprobe am Vortag
- **Voki** reagiert auf Antworten und sammelt Accessoires pro gemeisterter Unit
- XP, Combo, Tagesziel, Serie mit Wochen-Joker, freiwillige Wochen-Liga, Eltern-Ansicht für Admins

- Web-App: React + Vite (`src/`)
- Backend: Supabase (`supabase/schema.sql`, `supabase/functions/`)
- Einrichtung: siehe **SETUP.md**
